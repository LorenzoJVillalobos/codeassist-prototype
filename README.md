# CodeAssist — CMPA 4302 Project 01

**Interactive prototype** (no dependencies; static HTML/CSS/JavaScript).

## Running locally
Open `index.html` in your browser. To publish it, create a GitHub repository (for example `codeassist-prototype`), upload `index.html` to the repository root, and enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → /(root)**. The published URL will follow the form `https://YOUR-USERNAME.github.io/codeassist-prototype/` once GitHub Pages is enabled.

## Main task
1. Search for **deck guard** (publication **IRC**, edition **2021**, jurisdiction context **New Mexico**).
2. Select **R312.1 | Guards** in results.
3. View the publisher name and link; verify applicable code language and local adoption outside this prototype.
4. Add a personal note and select **Save reference**.
5. View **Saved references**, reopen, edit, or remove the reference.

## Limitations
- The database is a *demonstration catalog*, not an authoritative or complete code index.
- The official-source links go to each publisher's library, not necessarily to the specific section.
- Selecting New Mexico records a jurisdictional context, but it does not confirm whether the chosen edition is legally adopted, or if any amendments apply.
- It does **not** quote protected code text, interpret code requirements, or perform compliance evaluations.
- Saved references are browser-local (localStorage); there is no server, account, or multi-device sync.
- To assess real usefulness, conduct task-based tests against browser bookmarks and existing subscription tools.
